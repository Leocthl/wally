# Facts register

- **Single source** for every number, fee, limit, stat and date. Other docs cite the ID (`[F1]`, or a field: `[F1.ceiling]`). A value that differs from this file is a bug.
- **Honesty rule**: a rate, fee, cashback % or points value that a teammate has not observed and timestamped is a fabrication. READ-BY-CLAUDE stays provisional until re-captured.
- **Edit policy**: lead only during the planning pass. After that, change row, source and date together in one commit.
- **Exempt from the register**: ID labels (R1, I3, S2, DM4), design tokens ([04](04-design-language.md)), TASKS.md estimates, doc length caps.

| Status | Meaning |
|---|---|
| READ-BY-CLAUDE | Read from the public source on the date shown. Teammate re-capture still owed. |
| OBSERVED(date) | Teammate screenshot + timestamp, logged in `data/capture-sheet.md`. |
| VENDOR-REPORTED | Vendor's own claim. We publish only what we MEASURE. |
| MEASURED(n) | Our own run: n samples, seed and commit recorded. |
| SIMULATED | Scenario data we invented. Labelled in every UI. |
| ASSUMED | Planning parameter. Change the row, not the doc. |
